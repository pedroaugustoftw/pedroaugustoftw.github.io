# PetVet — GitHub Pages

Site: https://pedroaugustoftw.github.io/

Código-fonte: https://github.com/pedroaugustoftw/PetVet

O workflow `Deploy PetVet to GitHub Pages` busca a branch `main` do repositório PetVet, instala dependências, faz o build estático e publica neste endereço raiz. Para publicar novas alterações do PetVet, execute este workflow pela aba Actions (Run workflow). Não há tokens pessoais armazenados no repositório: a publicação utiliza o token nativo do GitHub Actions.
